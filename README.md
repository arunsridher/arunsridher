### 🚀 Engineering Philosophy
I build robust, high-throughput enterprise platforms for the logistics domain. My focus isn't just on writing code that works, but engineering systems that scale efficiently. Whether it's shaving off milliseconds on API responses or managing complex asynchronous queues, I enjoy deep-diving into backend optimization and modern web architectures.

*   **Current Focus:** Architecting enterprise logistics solutions that handle complex workflows and large-scale data points.
*   **Performance Obsession:** Leveraging **Bun**, **Hono**, and **Redis** for ultra-fast, low-latency backend services.
*   **Core Stack:** End-to-end development leaning heavily on **Next.js**, **TypeScript**, and the **MERN** ecosystem.
*   **Beyond the Screen:** Catching up on the latest movies, re-watching top-tier anime, and exploring emerging tech trends.
